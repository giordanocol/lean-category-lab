# lean-category-lab

A public learning repository for Lean theorem proving and category theory.

## Goal

Learn Lean theorem proving while building a progressively deeper understanding of category theory and formal mathematics.

## Method

The workflow is:

1. understand the mathematics informally;
2. formalize the statement and proof in Lean;
3. compare the result with Mathlib conventions and existing abstractions.

## Current status

Foundational material completed through:

* propositional logic;
* equality and rewriting;
* functions, injectivity, surjectivity, composition, image, and preimage.

The repository will evolve as the course moves toward algebraic structures and category theory.

Added experiments on algebraic structures, inheritance, and typeclass instance synthesis.
