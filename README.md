# lean-category-lab

A public learning repository for Lean theorem proving and category theory.

## Goal

Learn Lean theorem proving while building a progressively deeper understanding of category theory, formal mathematics, and the abstractions used in Mathlib.

## Method

The workflow is:

1. understand the mathematics informally;
2. formalize the statement and proof in Lean;
3. inspect the relevant Mathlib API;
4. compare the result with Mathlib conventions, abstractions, and existing lemmas.

## Current status

Foundational material completed through:

* propositional logic;
* equality and rewriting;
* functions;
* injectivity and surjectivity;
* function composition;
* image and preimage;
* basic set reasoning.

Additional experiments completed on:

* algebraic structures;
* structure inheritance;
* typeclasses and instance synthesis;
* generic algebraic and order-theoretic APIs.

Mathlib literacy work now includes:

* `#check`;
* `#print`;
* `#synth`;
* `exact?`;
* `apply?`;
* `simp?`;
* Go to Definition;
* Find References;
* source navigation;
* discovering lemmas without knowing their exact names in advance.

A dedicated Mathlib literacy exercise set was completed by locating and using 20 relevant lemmas across equality, order, sets, functions, and basic algebra.

## Direction

The repository will continue toward increasingly abstract mathematics, including:

* algebraic structures;
* order structures;
* reusable generic proofs;
* category theory;
* categorical constructions and formalized abstractions in Mathlib.

The long-term goal is not only to prove statements in Lean, but to become fluent in reading, navigating, and extending mathematical APIs in a style compatible with Mathlib.
